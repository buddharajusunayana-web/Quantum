# Quantum Algorithms & Cryptanalysis Portfolio

This repository contains Python and Qiskit Jupyter Notebooks demonstrating quantum computing algorithms, cryptographic protocols, and complexity benchmarking.

## Key Modules
- **`Linear_Cryptanalysis_of_AES.ipynb`**: Implementation and evaluation of linear cryptanalysis techniques on cipher structures.
- **`QKD_(BB84).ipynb`**: Simulation of the BB84 Quantum Key Distribution protocol.
- **`Entanglement.ipynb` & `2_qubit_gates.ipynb`**: Foundational multi-qubit state preparations and gate transformation benchmarking.
